## Notas Importantes

### Monedas
- **USD (Dólar)**: Usado en Ecuador, El Salvador y Panamá
- **EUR (Euro)**: Usado en España
- **Todas las demás**: Monedas locales específicas

### Locales
- **Brasil**: `pt-BR`
- **Todos los demás**: `es` (español genérico)

### Timezones
- Todos los países de América Latina usan timezones `America/*`
- España usa `Europe/Madrid`

## Uso en el Sistema

Este archivo sirve como referencia para:
1. Dropdowns de selección de país
2. Mapear país → moneda
3. Mapear país → timezone
4. Validar códigos
